# qBittorrent Auto Updater для Windows

Маленькая утилита, которая сама держит qBittorrent в актуальной версии и убирает окно
«Доступна новая версия — хотите обновиться?», чтобы вы больше никогда его не видели.

Настраивается один раз одной командой. Дальше при каждом включении компьютера утилита тихо
проверяет, не вышел ли новый qBittorrent, и устанавливает его ещё до того, как вы откроете
программу. Никаких окон, никаких вопросов, никаких установщиков руками.

Это один PowerShell-файл, который использует только то, что уже есть в Windows. Ничего
дополнительно ставить не нужно.

---

## Что она делает

* При каждом входе в Windows проверяет официальную страницу qBittorrent на GitHub.
* Скачивает официальный установщик и проверяет его SHA-256 перед запуском — если контрольную
  сумму сверить не удалось, обновление не выполняется, а не ставится непроверенным.
* Тихо устанавливает обновление при закрытом qBittorrent и снова открывает клиент, если он
  был запущен — с обычными правами пользователя, никогда не от имени администратора.
* Отключает вопрос об обновлении внутри самого qBittorrent — проверять обновления теперь
  задача утилиты.
* Сама подбирает подходящий установщик для вашей системы.

## Что нужно

* Windows 10 или 11 (64 бита)
* Установленный qBittorrent, запущенный хотя бы один раз
* Доступ в интернет к `github.com`

## Команда 1 — включить автообновление (рекомендуется)

1. Скачайте `qbt-updater.ps1` в любую папку (или дважды кликните `install.cmd` и переходите
   к шагу 4).
2. Откройте PowerShell в этой папке: зажмите `Shift`, кликните правой кнопкой по пустому
   месту в папке и выберите **«Открыть окно PowerShell здесь»** (или введите `powershell` в
   адресной строке Проводника).
3. Выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Install
   ```

4. Windows один раз спросит разрешение администратора — нажмите **Да**.

Готово. Утилита скопирует себя в `C:\ProgramData\qBittorrentUpdater` (постоянное место, так
что скачанную копию можно удалить), создаст скрытую задачу планировщика и отключит вопрос об
обновлении в qBittorrent. Дальше обновления будут ставиться сами при каждом входе в систему.

## Команда 2 — только убрать вопрос об обновлении (без автообновления)

Если нужно лишь, чтобы окно «хотите обновиться?» больше не появлялось:

```powershell
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -HidePopup
```

Команда меняет одну настройку внутри qBittorrent и больше ничего: никаких задач
планировщика, никаких установок. Права администратора не нужны. Если qBittorrent запущен, он
на минуту закроется и откроется снова — это обязательно, потому что клиент перезаписывает
файл настроек при выходе.

## Как всё отменить

1. Нажмите `Win + R`, введите `taskschd.msc`, нажмите Enter.
2. В **Библиотеке планировщика заданий** найдите **qBittorrent Auto Updater**, кликните по
   нему правой кнопкой и выберите **Удалить**.
3. При желании удалите папку `C:\ProgramData\qBittorrentUpdater`.
4. Чтобы вернуть вопрос об обновлении: закройте qBittorrent, откройте файл
   `%APPDATA%\qBittorrent\qBittorrent.ini` в Блокноте и удалите строку
   `Advanced\updateCheck=false`.

Сам qBittorrent эта утилита никогда не изменяет и не удаляет.

## Если что-то пошло не так

Всё, что делает утилита, записывается в лог-файл:

```
%LOCALAPPDATA%\qBittorrentUpdater\updater.log
```

Откройте его Блокнотом и посмотрите последние строки. Результат каждого запуска также
кодируется кодом возврата:

| Код | Значение |
|---|---|
| `0` | Успех или уже актуальная версия |
| `1` | Непредвиденная ошибка |
| `2` | qBittorrent не установлен |
| `3` | Не удалось определить последнюю версию |
| `4` | Не удалось отключить вопрос об обновлении |
| `5` | Разрешение администратора не выдано |
| `6` | Не удалось закрыть qBittorrent |
| `7` | Ошибка загрузки или установки |
| `8` | Установщик отработал, но результат неожиданный |
| `9` | Контрольную сумму не удалось проверить, обновление отклонено |

Если в qBittorrent включено «сворачивать в трей», клиент может не закрыться с первого раза —
тогда утилита закроет его принудительно, а торренты после обновления продолжатся с того же
места.

## Планы

* **Windows** — готово, это то, что делает скрипт сегодня.
* **macOS** — в планах: те же две команды, но через LaunchAgent вместо планировщика задач.
* **Linux** — в планах: версия на shell с systemd-таймером пользователя.
