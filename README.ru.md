# qBittorrent Auto Updater (Windows) — на русском

Надоело, что qBittorrent каждые две недели спрашивает: «Доступна новая версия — обновить?»,
и что установщик после этого всё равно приходится скачивать руками? Этот скрипт делает обе
работы за вас.

Всё — один PowerShell-файл. Без winget, без модулей, без своего установщика: если есть Windows
и PowerShell, ставить больше ничего не нужно.

**Что он делает:**

* ✅ Проверяет последний официальный релиз на GitHub qBittorrent (при каждом входе в систему).
* ✅ Скачивает официальный установщик, проверяет его SHA-256 и ставит тихо.
* ✅ Если qBittorrent был запущен — перезапускает его после обновления, торренты продолжаются
  с сохранённого места.
* ✅ Отключает встроенное окно «обновить?» — вопрос больше не появится.
* ✅ Умеет следить за каналом **stable** или **beta** — на ваш выбор.
* ✅ Сам подбирает нужную сборку: libtorrent 2.x или 1.2.x, как у вас установлено.

---

## Быстрый старт (одна команда, один раз)

```powershell
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Install
```

Или просто дважды кликните `install.cmd`.

Windows один раз покажет запрос UAC (задаче нужны права администратора, чтобы обновлять
системную установку). Подтвердите — и про обновления qBittorrent можно забыть. Команда делает
две вещи:

1. Создаёт задачу планировщика, которая **при каждом входе в Windows** тихо проверяет
   обновления. Включили компьютер — свежий релиз, если он вышел, ставится ещё до того, как вы
   откроете клиент.
2. Пишет `Advanced\updateCheck=false` в `qBittorrent.ini`, чтобы сам клиент перестал
   спрашивать про обновления. Теперь это работа скрипта.

## Остальные команды

Понадобятся редко — всё это необязательно.

```powershell
# Проверить и установить обновление прямо сейчас
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Update

# Только показать версии, ничего не менять
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Check

# Удалить задачу планировщика (обновления прекратятся, сам qBittorrent не трогается)
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Uninstall
```

## Параметры

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `-Install` | переключатель | - | Создать задачу и отключить окно об обновлениях. |
| `-Uninstall` | переключатель | - | Удалить задачу. |
| `-Update` | переключатель | - | Проверить и установить обновление (действие по умолчанию). |
| `-Check` | переключатель | - | Только показать версии, ничего не менять. |
| `-Channel` | `stable`, `beta` | `stable` | `beta` следит и за пре-релизами вроде `5.3.0beta1`. |
| `-Variant` | `auto`, `lt2`, `lt12` | `auto` | Какую сборку libtorrent ставить. `auto` определяет по установленной DLL. |
| `-LogonDelayMinutes` | минуты | `0` | Задержка после входа. `0` — проверка сразу. |
| `-TaskName` | строка | `qBittorrent Auto Updater` | Имя задачи планировщика. |
| `-LogPath` | путь | `%LOCALAPPDATA%\qBittorrentUpdater\updater.log` | Куда писать лог. |

Например, чтобы следить за бетами и дать системе пять минут на старт после входа:

```powershell
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Install -Channel beta -LogonDelayMinutes 5
```

## Как проходит обновление

1. Установленная версия читается из реестра и из `qbittorrent.exe`.
2. Последний релиз берётся через GitHub API, а если API упёрся в лимит — через редирект
   `/releases/latest`, так что проверка работает в любом случае.
3. Подбирается нужный официальный установщик: libtorrent 2.x или 1.2.x, 64-битный x64
   (это единственная архитектура Windows, которую публикует qBittorrent).
4. qBittorrent закрывается аккуратно (25 секунд на это, потом принудительно).
5. Установщик скачивается, его SHA-256 сверяется с digest'ом из релиза, затем он ставится
   тихо (`/S`).
6. Проверяется итоговая версия, и если клиент был запущен — он перезапускается.

## Если что-то пошло не так

Всё, что делает скрипт, пишется в лог:

```
%LOCALAPPDATA%\qBittorrentUpdater\updater.log
```

Итог работы также кодируется кодом возврата:

| Код | Значение |
|---|---|
| `0` | Успех или уже актуальная версия |
| `1` | Непредвиденная ошибка |
| `2` | qBittorrent не установлен |
| `3` | Не удалось определить последнюю версию |
| `5` | Требовались права администратора, но не получены |
| `6` | Не удалось закрыть qBittorrent |
| `7` | Ошибка загрузки или установки |
| `8` | Установщик отработал, но итоговая версия неожиданная |

## Требования

* Windows 10 / 11, 64 бита
* PowerShell 5.1 или новее — больше ничего
* Доступ в интернет к `github.com`
* Права администратора — один раз, только при настройке

## Замечания

* Если в qBittorrent включено «сворачивать в трей при закрытии», клиент может не завершиться
  с первого раза — тогда скрипт закроет его принудительно. Торренты продолжатся с
  сохранённого состояния.
* Скрипт не хранит никаких учётных данных. Запись идёт только во временную папку, лог-файл,
  каталог установки qBittorrent и единственный ключ `Advanced\updateCheck` в
  `qBittorrent.ini`.
