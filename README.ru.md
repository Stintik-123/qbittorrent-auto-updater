# qBittorrent Auto Updater (Windows) — на русском

Один маленький PowerShell-скрипт, который сам обновляет qBittorrent и больше никогда не
показывает окно «Доступна новая версия, хотите обновиться?».

* **Всё в одном файле.** Без зависимостей, без winget, без модулей — ничего доустанавливать не нужно.
* **Без присмотра.** Запускается из планировщика с повышенными правами, UAC-запроса не будет.
* **Только официальные источники.** Установщик качается с официального релиза на GitHub,
  и его SHA-256 сверяется перед запуском.

---

## Установка (одна команда, один раз)

```powershell
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Install
```

Эта команда:

1. Создаёт задачу планировщика, которая тихо обновляет qBittorrent **сразу после входа в Windows**,
   так что свежий релиз подхватится при каждом включении машины.
2. Пишет `Advanced\updateCheck=false` в `qBittorrent.ini`, чтобы клиент перестал приставать с
   обновлениями — эту работу теперь делает скрипт.

Один раз спросит права администратора (задаче они нужны, чтобы обновлять системную установку).
Дальше всё происходит само.

Можно просто дважды кликнуть `install.cmd`.

## Остальные команды

```powershell
# Обновить прямо сейчас
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Update

# Только показать версии, ничего не менять
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Check

# Удалить задачу планировщика
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Uninstall
```

## Ключи

| Параметр | Значения | По умолчанию | Смысл |
|---|---|---|---|
| `-Install` | переключатель | - | Создать задачу и отключить popup обновлений. |
| `-Uninstall` | переключатель | - | Удалить задачу. |
| `-Update` | переключатель | - | Проверить и установить обновление (действие по умолчанию). |
| `-Check` | переключатель | - | Только показать версии, ничего не менять. |
| `-Channel` | `stable`, `beta` | `stable` | Какой канал релизов отслеживать. |
| `-Variant` | `auto`, `lt2`, `lt12` | `auto` | `auto` определяет текущую сборку libtorrent по DLL. |
| `-LogonDelayMinutes` | минуты | `0` | Задержка после входа. `0` — проверка начинается немедленно. |
| `-TaskName` | строка | `qBittorrent Auto Updater` | Имя задачи планировщика. |
| `-LogPath` | путь | `%LOCALAPPDATA%\qBittorrentUpdater\updater.log` | Куда писать лог. |

## Когда это срабатывает

Один режим: **сразу после входа в Windows**. Включил компьютер, вошёл в систему — обновлятор
тут же проверяет, вышел ли новый релиз qBittorrent, и ставит его, если да. Ничего запоминать
не надо, никакого фиксированного времени.

Если хочется дать системе больше времени на старте, добавь задержку в минутах:

```powershell
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Install -LogonDelayMinutes 5
```

## Как происходит обновление

1. Установленная версия читается из реестра и из `qbittorrent.exe`.
2. Последний релиз берётся через GitHub API, а если API упрётся в лимит — через редирект
   `/releases/latest` (без лимитов).
3. Подбирается нужный официальный установщик (libtorrent 2.x или 1.2.x, x64 или arm64).
4. qBittorrent закрывается, установщик скачивается, его SHA-256 сверяется с digest'ом из
   релиза, затем запускается тихо (`/S`).
5. Проверяется итоговая версия, и клиент перезапускается, если он работал.

## Коды возврата

| Код | Значение |
|---|---|
| `0` | Успех или уже актуальная версия |
| `1` | Непредвиденная ошибка |
| `2` | qBittorrent не установлен |
| `3` | Не удалось определить последнюю версию |
| `5` | Требовались права администратора, но не получены |
| `6` | Не удалось закрыть qBittorrent |
| `7` | Ошибка загрузки или установки |
| `8` | Установщик отработал, но версия неожиданная |

## Требования

* Windows 10 / 11 (подойдёт и Windows 7 с PowerShell 5.1)
* PowerShell 5.1 или новее — больше ничего не нужно
* Доступ в интернет к `github.com`
* Права администратора — один раз, только на настройку

## Замечания

* Если в qBittorrent включено «сворачивать в трей при закрытии», клиент может не завершиться
  с первого раза — тогда скрипт закрывает его принудительно. Торренты продолжатся с
  сохранённого состояния.
* Скрипт не хранит никаких учётных данных. Запись идёт только во временную папку, лог-файл,
  каталог установки qBittorrent и единственный ключ `Advanced\updateCheck` в `qBittorrent.ini`.
