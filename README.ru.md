# qBittorrent Auto Updater

[English](README.md) | **Русский**

Маленькая утилита, которая сама держит qBittorrent в актуальной версии и убирает окно
«Доступна новая версия — хотите обновиться?», чтобы вы больше никогда его не видели.

Настраивается один раз одной командой. Дальше при каждом включении компьютера утилита тихо
проверяет, не вышел ли новый qBittorrent, и устанавливает его ещё до того, как вы откроете
программу. Никаких окон, никаких вопросов, никаких установщиков руками.

Работает на **Windows**, **macOS** и **Linux**. По одному скрипту на платформу, используются
только возможности самой системы. Ничего дополнительно ставить не нужно.

## Что она делает

* При каждом входе в систему проверяет официальную страницу qBittorrent на GitHub.
* Скачивает официальный установщик и проверяет его SHA-256 перед запуском — если контрольную
  сумму сверить не удалось, обновление не выполняется, а не ставится непроверенным.
* Тихо устанавливает обновление при закрытом qBittorrent и снова открывает клиент, если он
  был запущен — с обычными правами пользователя.
* Отключает вопрос об обновлении внутри самого qBittorrent — проверять обновления теперь
  задача утилиты.
* Сама подбирает подходящий установщик для вашей системы.

## Windows

**Что нужно:** Windows 10 или 11 (64 бита), установленный qBittorrent, запущенный хотя бы
один раз.

### Команда 1 — включить автообновление (рекомендуется)

1. Скачайте `qbt-updater.ps1` в любую папку (или дважды кликните `install.cmd` и переходите
   к шагу 4).
2. Откройте PowerShell в этой папке: зажмите `Shift`, кликните правой кнопкой по пустому
   месту в папке и выберите **«Открыть окно PowerShell здесь»** (или введите `powershell` в
   адресной строке Проводника).
3. Выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -Install
   ```

4. Windows один раз спросит разрешение администратора — нажмите **Да**.

Готово. Утилита скопирует себя в `C:\ProgramData\qBittorrentUpdater` (постоянное место, так
что скачанную копию можно удалить), создаст скрытую задачу планировщика и отключит вопрос об
обновлении в qBittorrent. Дальше обновления будут ставиться сами при каждом входе в систему.

### Команда 2 — только убрать вопрос об обновлении (без автообновления)

```powershell
powershell -ExecutionPolicy Bypass -File .\qbt-updater.ps1 -HidePopup
```

Команда меняет одну настройку внутри qBittorrent и больше ничего: никаких задач
планировщика, никаких установок. Права администратора не нужны. Если qBittorrent запущен, он
на минуту закроется и откроется снова — это обязательно, потому что клиент перезаписывает
файл настроек при выходе.

### Как всё отменить

1. Нажмите `Win + R`, введите `taskschd.msc`, нажмите Enter.
2. В **Библиотеке планировщика заданий** найдите **qBittorrent Auto Updater**, кликните по
   нему правой кнопкой и выберите **Удалить**.
3. При желании удалите папку `C:\ProgramData\qBittorrentUpdater`.
4. Чтобы вернуть вопрос об обновлении: закройте qBittorrent, откройте файл
   `%APPDATA%\qBittorrent\qBittorrent.ini` в Блокноте и удалите строку
   `Advanced\updateCheck=false`.

## macOS

**Что нужно:** macOS с qBittorrent в `/Applications`, запущенным хотя бы один раз. Для
проверки контрольных сумм нужен `python3` или `jq` (один из них обычно уже установлен).

> **Важно:** начиная с qBittorrent 5.3.0 официальные релизы на GitHub больше не содержат
> установщик для macOS (`.dmg`). Утилита не делает ничего опасного: она видит, что
> установщика нет, сообщает об этом (код возврата `10`) и ничего не устанавливает.
> Автообновление на macOS снова заработает, как только официальные `.dmg` вернутся в релизы.

### Команда 1 — включить автообновление (рекомендуется)

1. Скачайте `qbt-updater.sh` в любую папку.
2. Откройте Терминал и перейдите в эту папку (`cd ~/Downloads`, если скачали туда).
3. Выполните:

   ```bash
   bash qbt-updater.sh install
   ```

Готово. Утилита скопирует себя в `~/Library/Application Support/qBittorrentUpdater`,
зарегистрирует LaunchAgent, который запускается при каждом входе в систему, и отключит
вопрос об обновлении в qBittorrent. Обновления ставятся из официального `.dmg` в
`/Applications` — пароль администратора не запрашивается никогда.

### Команда 2 — только убрать вопрос об обновлении (без автообновления)

```bash
bash qbt-updater.sh hide-popup
```

Меняется только настройка внутри qBittorrent: без LaunchAgent, без обновлений. Если
qBittorrent запущен, он на минуту закроется и откроется снова.

### Как всё отменить

1. Откройте Терминал и выполните:
   `launchctl unload ~/Library/LaunchAgents/com.qbittorrent.autoupdater.plist`
2. Удалите файлы: `rm ~/Library/LaunchAgents/com.qbittorrent.autoupdater.plist` и папку
   `~/Library/Application Support/qBittorrentUpdater`.
3. Чтобы вернуть вопрос об обновлении: закройте qBittorrent, откройте файл
   `~/Library/Preferences/qBittorrent/qBittorrent.ini` в текстовом редакторе и удалите
   строку `Advanced\updateCheck=false`.

## Linux

**Что нужно:** любой дистрибутив, где qBittorrent установлен как **официальный AppImage**, и
запущенный хотя бы один раз. Если qBittorrent установлен из пакетов дистрибутива (apt, dnf,
pacman…), его обновляет пакетный менеджер — утилита туда не лезет. Для проверки контрольных
сумм нужен `python3` или `jq` — на большинстве систем что-то из этого уже есть.

### Команда 1 — включить автообновление (рекомендуется)

1. Скачайте `qbt-updater.sh` в любую папку.
2. Откройте терминал и перейдите в эту папку.
3. Выполните:

   ```bash
   bash qbt-updater.sh install
   ```

Готово. Утилита скопирует себя в `~/.local/share/qBittorrentUpdater`, добавит запись
автозапуска, которая срабатывает при каждом входе в систему, и отключит вопрос об обновлении
в qBittorrent. Обновления заменяют ваш AppImage на месте.

### Команда 2 — только убрать вопрос об обновлении (без автообновления)

```bash
bash qbt-updater.sh hide-popup
```

Меняется только настройка внутри qBittorrent: без автозапуска, без обновлений. Если
qBittorrent запущен, он на минуту закроется и откроется снова.

### Как всё отменить

1. Удалите запись автозапуска: `rm ~/.config/autostart/qbittorrent-auto-updater.desktop`
2. Удалите папку `~/.local/share/qBittorrentUpdater`.
3. Чтобы вернуть вопрос об обновлении: закройте qBittorrent, откройте файл
   `~/.config/qBittorrent/qBittorrent.ini` в текстовом редакторе и удалите строку
   `Advanced\updateCheck=false`.

## Если что-то пошло не так

Всё, что делает утилита, записывается в лог-файл:

| Платформа | Лог-файл |
|---|---|
| Windows | `%LOCALAPPDATA%\qBittorrentUpdater\updater.log` |
| macOS | `~/Library/Logs/qBittorrentUpdater.log` |
| Linux | `~/.local/state/qbittorrent-updater.log` |

Откройте его и посмотрите последние строки. Результат каждого запуска также кодируется кодом
возврата:

| Код | Значение |
|---|---|
| `0` | Успех или уже актуальная версия |
| `1` | Непредвиденная ошибка или неверное использование |
| `2` | qBittorrent не установлен (или установка не поддерживается) |
| `3` | Не удалось определить последнюю версию |
| `4` | Не удалось отключить вопрос об обновлении |
| `5` | Разрешение администратора не выдано (только Windows) |
| `6` | Не удалось закрыть qBittorrent |
| `7` | Ошибка загрузки или установки |
| `8` | Установщик отработал, но результат неожиданный |
| `9` | Контрольную сумму не удалось проверить, обновление отклонено |
| `10` | В этом релизе нет установщика для вашей платформы (macOS с версии 5.3.0) |

Если в qBittorrent включено «сворачивать в трей», клиент может не закрыться с первого раза —
тогда утилита закроет его принудительно, а торренты после обновления продолжатся с того же
места.
